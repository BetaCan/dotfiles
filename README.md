# Terminal dotfiles

This repository stores my shell and terminal emulator configuration.

## Contents

- `bash/` - Bash startup files
- `kitty/` - Kitty configuration
- `alacritty/` - Alacritty configuration
- `foot/` - Foot configuration
- `ghostty/` - Ghostty configuration

These files are organized so they can be copied into the matching locations
under `$HOME` on a fresh Arch Linux installation.

Private keys, tokens, and passwords must not be added to this repository.
